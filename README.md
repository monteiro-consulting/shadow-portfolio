# Shadow Portfolio

A written call on a living company, dated, carrying the condition that would prove it wrong. One file per company.

## Why

An investor earns credibility by committing capital and letting the record be checked years later. I haven't committed any. So the record gets built the other way round: every call here is public the day it is written, and time does the checking.

No positions, no capital, nothing for sale.

## The rules

**The date is the asset, not the text.** A 2026 call cannot be written in 2028. That is the whole reason this sits in a public repository: the commit history is the timestamp.

**Nothing gets edited afterwards.** A call I got wrong stays exactly as I wrote it. Corrections go in a dated `Review` block at the bottom of the same file. If you doubt that, read the history.

**Every call names what would prove it wrong.** "I believe in this team" never resolves. "If headcount is still under 15 by September 2027, I read their sales motion wrong" resolves on its own.

**Public data only, every figure sourced.** Where a number should exist and I don't have it, the entry says unknown. A plausible guess would cost more than the gap.

## Scoring

Every six months each entry gets reopened and a dated block appended. The misses carry more than the hits: ten calls right looks like luck, six right with the reasoning still attached shows whether the reading sharpened.
